# Haris — personal mark (master v1)

"A continuous form whose ending sits exactly one step above its beginning."

## Files
- svg/mark-black.svg, mark-white.svg — display master (use ≥ 24px)
- svg/mark-black-red.svg, mark-white-red.svg — optional "now" state (red = the arriving last stretch of the lap)
- svg/mark-reversed-square.svg — white on black tile
- svg/favicon.svg, mark-small-16-*.svg — small master (heavier, step snapped to whole pixel) for ≤ 20px
- svg/mark-construction.svg — expressive "still being built" state. Not the logo.
- png/ — transparent marks 256–2048, avatars 1080, favicons 16/32/48, apple-touch 180

## Geometry (100-unit grid)
- Display: outer Ø72, weight 16, counter Ø40, lap rises 16 (= weight). Centre of lap (50, 58).
- Small: outer Ø76, weight 18, rise 18.
- Terminals cut flat on the vertical axis. No rounding.

## Colour
- Black #000000 · White #FFFFFF · Red #D9431E (optional, never the whole mark)

## Usage
- Clear space: one step (16 units) on all sides.
- Lockup with HARIS: mark height ≈ 1.3 × cap height, gap = one step.
- Always legible in pure black first. Red is punctuation, used rarely.
